Load balancing

Spread connections across backend pools entirely in userspace, keeping latency and CPU overhead predictable under high concurrency.

HTTP throughput validated at 82 to 90 Gbps

Firewall

Apply stateful filtering directly in the data path instead of bouncing packets through the kernel, so policy enforcement keeps pace with forwarding.

L3 forwarding validated at 200 Gbps on 1 core

VPN

Terminate site-to-site and remote-access IPsec tunnels entirely in userspace, keeping encrypted throughput close to unencrypted forwarding speeds.

IPsec VPN validated at 92 Gbps software, 96 Gbps with QAT

High-throughput data movement

Carry storage-heavy and bulk transfer traffic across the fleet on the same high-throughput packet path used for every other workload.

HTTP (2MB files) throughput validated at 82 to 85 Gbps

Production deployment patterns

Edge load balancer

Front multiple application pools with userspace connection distribution, then leave origin services unchanged behind it.

Inline firewall

Keep security policy and forwarding on the same software path instead of splitting routing and filtering across separate boxes.

Site-to-site VPN

Terminate IPsec tunnels in userspace and carry encrypted traffic at the same throughput as unencrypted forwarding.

High-throughput data movement

Move storage-heavy and bulk transfer traffic across the fleet on the same packet path used for every other workload.

Scale features by core, not by appliance

Whether the node is fronting a VPN gateway, enforcing firewall policy, or handling high-throughput data movement, performance scales linearly with core count from Intel Atom through Xeon Scalable, on the hardware you already run.
